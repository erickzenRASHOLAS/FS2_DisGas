# Frontend React — Gas El Volcán

Este directorio contiene la aplicación React + Vite recomendada para probar los flujos corregidos.

## Comandos

```bash
npm ci
npm run dev
```

Para comprobar la compilación: `npm run build`. Para revisar reglas de estilo: `npm run lint`.

Los usuarios, pedidos, asignaciones, inventario y cobros se simulan con `localStorage` mediante `src/services/datosMock.js`. Esta capa solo existe para probar el frontend; no sustituye una API ni una base de datos. Las credenciales de prueba se documentan en el README de la raíz del proyecto.
